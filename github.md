Git Repositories: Unlimited public/private repositories with branching, forking, and merging.
Pull Requests (PRs): Code review, discussions, and inline comments.
GitHub Actions: Automate workflows, build, test, and deploy code directly.
GitHub Codespaces: Instant, cloud-hosted development environments.
GitHub Copilot: AI pair programmer that suggests code and functions.
Git LFS: File storage for large assets. 
Issues: Track bugs, enhancements, and tasks.
Projects: Kanban-style boards and roadmaps to plan work.
